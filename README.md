# Lab2026-Testing
Aimed at testing the Practical Project Task website with test automation frameworks.
After cloning the repository for the first time, you should run following commands.
Install Dependencies:
   npm install
Install Playwright Browsers:
   npx playwright install
Install Reporter (if needed):
   npm install -D monocart-reporter
Run All Tests:
   npx playwright test
Run Specific Test File:
   npx playwright test tests/exploreDiscography.spec.ts
